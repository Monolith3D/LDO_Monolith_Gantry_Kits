# Images

This folder contains reference images for the LDO Monolith Gantry Kit repo.

- `Renders` contains clean kit and part renders.
- `V2` contains V2 kit package, hardware, and part reference photos.
- `VT` contains VT kit package, hardware, and part reference photos.
- `Batch_1` contains Batch 1 issue reference images linked from the batch notes.
