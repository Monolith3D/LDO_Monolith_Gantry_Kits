# LDO Monolith Milled Z-Joint Kit

[Repository overview](README.md)

CNC-milled metal replacements for the hybrid Z-joints supplied with the LDO Monolith V2 Gantry Kit. **This Z-joint kit is sold separately from the main gantry kit.**

## Compatibility

- **Only compatible with the LDO Monolith V2 Gantry Kit.**
- **Not compatible with printed or sheet-metal Monolith gantries.**

## Features

- **Heat resistance:** Metal construction provides greater heat resistance than hybrid joints.
- **Controlled rotational compliance:** Included spacers create a smaller clamping surface, designed to reduce the risk of binding compared to other rigid metal Z-joints.
- **Matching finish:** Bead-blasted and black-anodized to match the LDO gantry.
- **Cable management:** M3 threaded mounting hole for cable clips.
- **Double-Z support:** Use two kits with two compatible carriages on each Z rail.

## Installation

Select the milled Z-joint option in [Monolith Builder](https://build.monolith3d.xyz/) for step-by-step installation guidance. These joints are not yet covered in the PDF manuals.

## Kit Contents

- 4 milled Z-joints
- 4 spacers
- M3 mounting screws

**M5 screws are reused from the gantry kit.**
