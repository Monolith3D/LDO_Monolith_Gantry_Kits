# User Mods

This folder is for community-made additions, adaptations, and compatibility parts for the LDO Monolith Gantry kits.

User mods are not official LDO kit files unless stated otherwise. Check the mod author, target printer, kit variant, drive layout, fit layout, and toolhead assumptions before printing or ordering parts.

Use the folder structure `username/usermod_name` for new user mods.

Good user mod folders should include:

- A short `README.md` explaining what the mod does
- Clear compatibility notes for V2 or VT, 2WD or AWD, and NP or FT where relevant
- STL, CAD, image, and BOM files needed to understand the mod
- Assembly notes or warnings if the mod changes belt path, endstops, travel, docks, panels, or toolhead clearance
- Credit and license notes when the mod reuses work from another project

Use user mods at your own risk. They may not receive updates when the main kit, manuals, or Monolith Gantry files change.
